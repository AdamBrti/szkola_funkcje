Jak to działa?

Funkcja to fragment programu, który wykonuje konkretne zadanie. Może coś policzyć, zmienić wartość albo coś wyświetlić.

Przykłady dla ucznia

Wskazówka

Zwróć uwagę, że każda funkcja ma nazwę i parametr. Parametr to liczba, którą podajesz do środka.

A tak wygląda to samo w C++

Poniżej masz trzy osobne funkcje zapisane w stylu C++. Każda robi coś innego, ale każda przyjmuje liczbę x.

Funkcja 1 int kwadrat(int x) 
int kwadrat(int x) {
  return x * x;
}
Funkcja 2 int podwoj(int x) 
int podwoj(int x) {
  return x * 2;
}
Funkcja 3 void pasekMocy(int x) 
void pasekMocy(int x) {
  for (int i = 0; i < x; i++) {
    cout << "#";
  }
}
Najważniejsze: w JavaScript kliknięcie przycisku uruchamia funkcję od razu na stronie, a w C++ podobną funkcję zapisujesz w kodzie programu i wywołujesz w swoim projekcie.

Ciekawsze funkcje (dla zabawy i nauki)

Liczba pierwsza bool czyPierwsza(int x) 
bool czyPierwsza(int x) {
  if (x < 2) return false;
  for (int i = 2; i < x; i++) {
    if (x % i == 0) return false;
  }
  return true;
}
