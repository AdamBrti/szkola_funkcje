Na początku: jak w szkole mówi się o stopniach?

W polskiej szkole podstawowej wyróżnia się 6 stopni w skali od 1 do 6 (w świetle wymogów wynikających m.in. z systemu oświaty i rozporządzeń MEN o ocenianiu wewnątrzszkolnym). Krótko, żebyśmy mówili tym samym językiem:

St. Opis słowny w polskiej szkole (skrót)
6celujący (ponad wymagania) — widać nie tylko spełnienie zadań, ale pewną swobodę w temacie
5bardzo dobry — rozumiesz, stosujesz, osiągasz założone wymagania w praktyce
4dobry — widać opanowanie, choć zdarzają się pomyłki albo niedociągnięcia
3dostateczny — spełniasz podstawowe wymagania, ale słabiej w szczegółach albo w samodzielności
2mierny — wymagania tylko częściowo; widać, że temat wymaga solidnej powtórki i wsparcia
1niedostateczny — wymagania w dużym stopniu niespełnione; wymagana dalsza, systematyczna pomoc nauczyciela (zgodnie z zasadami w szkole)

Na tej stronie z quizu wyskoczy propozycja stopnia — tak jak podpowiedź. W klasie ostateczne znaczenie ma rozmowa z nauczycielem, zadania w Dev-C++ i obserwacja na lekcji (zgodnie z zasadami, które macie w szkole: kryteria w szkole mogą być dopisane w regulaminie czy w zasadach oceniania).

Minimum w tym temacie — na „bardzo dobry” (5)

To jest pula umiejętności, którą możesz ogarniać tylko z tych slajdów, quizu i ćwiczeń: nic tu nie musi być tajemnicą, dopóki ćwiczysz. Chodzi o to, żeby tablica, indeksy od zera i pętla for nie były dla Ciebie „magią”, tylko planem działania.

Minimum, które tu masz wypisane wprost (cel: stopień 5 w tym zagadnieniu)

  • Wyjaśniasz, po co jest tablica, gdy jedna zmienna nie wystarcza.
  • Zapisujesz deklarację, np. int a[5]; albo int dane[10];.
  • Wiesz, że pierwszy indeks to 0, a ostatni to liczba elementów − 1.
  • Odczytujesz i zapisujesz element przez a[i] i wiesz, o co chodzi w cin >> a[i] oraz cout << a[i] (są też w slajdach 5–6 i podsumowaniu).
  • Rozumiesz pętlę for po tablicy i wiesz, po co jest warunek i < N, żeby pętla nie wyszła poza tablicę (sekcja 5 tłumaczy pętlę; samodzielnie: śledzisz i w głowie lub na kartce).
  • Potrafisz w kilku zdaniach powiedzieć, co dziś robi w programie main i do czego służą funkcje wprowadz_dane i wyprowadz_dane w pełnym przykładzie (sekcja 7).

Najwyższy stopień? — tę część wymyśl sam

Czym jest u Ciebie w tym module „celująco” — czy pełne porządku w pętli, zero wątpliwości przy ostatnim indeksie, naśladowanie pomyślnego planu, gdy czyta się kod, czy może wytłumaczenie go komuś w klasie? Na tej stronie celowo nie wklejamy gotowego spisu na 6 — w szkole ten stopień ma opis (celujący) i wychodzisz ponad wymagania; od Ciebie zależy, w czym w tym temacie chcesz być naprawdę pewnym siebie. Pytania z gwiazdką w quizie (★) tylko pilnują minimum; reszta drogi to Twoje zaangażowanie, dokładność w indeksach i łączenie slajdów 1–8 w jedną, spójną historię w głowie.

2. Czym jest tablica?

Tablica to kilka komórek pamięci pod jedną nazwą. Można ją traktować jak szafkę z ponumerowanymi przegródkami. Numer przegródki nazywamy indeksem.

Kliknij dowolną komórkę tablicy.

3. Deklaracja tablicy

W C++ najpierw podajemy typ danych, potem nazwę tablicy, a w nawiasach kwadratowych liczbę elementów.

Typ

int — liczby całkowite

Nazwa

a albo dane

Liczba pól

[5] oznacza 5 elementów

Przykłady deklaracji
int dane[5];

const int N = 5;
int a[N];

4. Indeksy zaczynają się od 0

To najważniejsza rzecz: pierwszy element tablicy w C++ ma indeks 0, nie 1. Dla tablicy pięcioelementowej ostatni indeks to 4.

Odwoływanie się do elementów
a[0]  a[1]  a[2]  a[3]  a[4]

// ogólnie dla N elementów:
a[0], a[1], ..., a[N - 1]

Jaki indeks ma ostatni element tablicy int dane[8];?

Podpowiedź: ostatni indeks to liczba elementów minus 1.

5. Wprowadzanie danych

Funkcja wprowadz_dane() przechodzi po kolejnych indeksach i wpisuje liczby do kolejnych komórek tablicy.

Funkcja wprowadzająca dane
void wprowadz_dane()
{
    for(int i = 0; i < N; i++)
    {
        cout << "Podaj dana nr " << i << ": ";
        cin >> a[i];
    }
}
🔁 for powtarza instrukcje kilka razy.
📍 i wskazuje aktualny indeks tablicy.
⌨️ cin >> a[i]; wpisuje liczbę do komórki.
🛑 i < N pilnuje, żeby nie wyjść poza tablicę.

6. Wypisywanie danych

Wypisywanie wygląda podobnie. Pętla przechodzi po indeksach i pokazuje zawartość każdej komórki.

Funkcja wypisująca dane
void wyprowadz_dane()
{
    for(int i = 0; i < N; i++)
    {
        cout << "Dane[" << i << "] = " << a[i] << endl;
    }
}

7. Pełny program

To kompletny przykład: najpierw tworzymy tablicę, potem wprowadzamy dane, a na końcu je wypisujemy.

Tablica.cpp
#include <iostream>
using namespace std;

const int N = 5;
int a[N];

void wprowadz_dane()
{
    for(int i = 0; i < N; i++)
    {
        cout << "Podaj dana nr " << i << ": ";
        cin >> a[i];
    }
}

void wyprowadz_dane()
{
    for(int i = 0; i < N; i++)
    {
        cout << "Dane[" << i << "] = " << a[i] << endl;
    }
}

int main()
{
    wprowadz_dane();
    wyprowadz_dane();
    return 0;
}
const int N = 5; — ustala, że tablica ma 5 elementów.
int a[N]; — tworzy tablicę liczb całkowitych.
void wprowadz_dane() — funkcja nic nie zwraca i nie ma parametrów.
for(int i = 0; i < N; i++) — przechodzi po indeksach 0, 1, 2, 3, 4.
cin >> a[i]; — wpisuje wartość do aktualnej komórki.
wyprowadz_dane(); — wywołuje funkcję wypisującą tablicę.

8. Symulator tablicy

Wpisz 5 liczb. Po kliknięciu przycisku zobaczysz, jak pętla for zapisuje kolejne wartości do komórek a[0], a[1], ..., a[4].

Tryb działania: najpierw wpisujemy dane tak jak przez cin >> a[i], potem wypisujemy je tak jak przez cout << a[i].
